### Selected work

**[Catalog Gatekeeper](https://github.com/UTSGJohnsonSong/catalog-gatekeeper)**<br>
An agent proposes fixes to a Shopify-style product catalog. Twelve deterministic checks, eleven of which can block a fix, and then a person decide what is written back. On a frozen synthetic test split written by the same author as the rules, the checks caught 323 of 330 known defects and wrongly blocked 2 of 102 clean fixes. The public demo runs on a simulated store, with fixes drafted by a template script. Start with the [overview page](https://utsgjohnsonsong.github.io/catalog-gatekeeper/).

**[Cleave](https://zekunsong.com/#work/cleave)**<br>
Finalist at the Boson AI Higgs Audio Hackathon 2026. Our three-person team built a real-time voice assistant that says the word a second-language speaker is stuck on, in their own cloned voice. I defined the WebSocket audio protocol between browser and server, built the React client, and designed the server's rule gate, which lets the assistant speak only on evidence it can check. There is a [demo video](https://zekunsong.com/assets/cleave-demo.mp4).

**[CardioTrace](https://github.com/UTSGJohnsonSong/cardiotrace)**<br>
A reproducible study of cardiovascular death risk on U.S. health survey data. It has 260 automated tests, CI gates reject stale analysis outputs, and downloads fail on any missing source file instead of skipping it silently. Read the [report](https://utsgjohnsonsong.github.io/cardiotrace/).

**Remeda**, Backend & Data Engineer, University of Toronto applied project<br>
Backend and data work for a clinical AI product, with no patient data (synthetic clinical notes and public coding references): terminology pipelines, mapping APIs, rerunnable bulk ETL with automated tests, and an evaluation of how well findings are extracted from clinical notes.

**WholeViz**, Development Lead, CSC301 industry partner project<br>
I led development for a six-person team extending an industry partner's Django analytics platform for non-technical users, and built Python modules for data-quality profiling, chart suggestions, dataset joins and role-permission checks.
